# Deneb template schema

`deneb-template-usermeta-v1.json` is Deneb's published JSON schema for version 1 template
metadata (`usermeta` with `metaVersion: 1`). It is copied unchanged from
https://deneb-viz.github.io/schema/deneb-template-usermeta-v1.json so that
`check-templates.mjs` can validate templates offline.
